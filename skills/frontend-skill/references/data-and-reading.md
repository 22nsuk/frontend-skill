# Data displays and reading flows

Use this reference when the requested change affects data displays, comparisons, evidence, or sustained reading. Apply only the relevant sections. Treat print and export as requirements only when they belong to the requested deliverable.

## Preserve substance

Identify what each value means before changing its presentation. Preserve real values, units, dates, populations, conditions, uncertainty, and source links. Keep distinctions between observations, estimates, projections, and interpretations. Do not turn a qualified finding into an unconditional headline.

Keep unknown, unavailable, not applicable, and zero distinguishable. Use an explicit missing-value label where ambiguity matters. Never fill gaps with plausible figures. Label intentional demo data clearly at the point of use and keep it distinguishable from real records.

Do not silently remove an existing claim because its support is missing. Mark its status as unresolved; ask when that uncertainty materially affects the requested result. Retain access to its existing source while resolving the issue.

Format numbers consistently within each semantic field. Choose precision, separators, signs, and abbreviations according to the measure and its meaningful accuracy. Do not force currencies, counts, rates, and durations into a shared decimal format. Preserve exact values where the task requires them, even when an overview uses rounded labels.

## Make comparisons legible

Choose a representation for the reader's question: tables for exact lookup, aligned bars or dots for magnitude, and lines for change across an ordered interval. Use equal-size small multiples when separate panels clarify repeated comparisons; share scales when comparing magnitude, and disclose necessary scale differences. Use sparklines for compact trend scanning only when the measure, time span, and units remain available nearby.

Provide meaningful axis labels, units, and series identification. Explain truncated or unusual scales. Prefer direct labels when they remain readable; otherwise provide a clear legend. Supplement color with text, position, shape, or line style so identification survives color loss. Keep labels and data associations intact on narrow screens.

## Support continuous reading

Give headings, summaries, body text, annotations, and references distinct roles. Keep the main argument readable in sequence. Keep conditions that change a conclusion beside that conclusion, including relevant uncertainty. Place source access near the claim or figure it supports.

Use progressive disclosure for secondary calculations, examples, or background when it reduces interruption. Keep disclosure summaries meaningful and source access discoverable. Do not hide essential qualifications or replace a document's reading flow with an invented control panel.

## Check the affected output

Check only behavior touched by the change: value and label accuracy, missing-data states, scale interpretation, source access, responsive associations, and any altered disclosure controls. Test printing or export when requested, including clipping, page breaks, legends, and essential conditions in the resulting artifact. Respect the application's existing delivery model. Do not require new interactions, a single-file format, or a theme change merely to apply this guidance. Limit claims about application behavior to what was verified.
