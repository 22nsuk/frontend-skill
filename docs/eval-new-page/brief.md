# 동네수리공방

동네수리공방은 생활용품을 방문 점검하고 수리하는 가상의 업체입니다. 아래 요금과 서비스는 예시입니다.

## 방문 서비스

- 소형 가전의 전원·부품 고장. 전기포트, 선풍기, 청소기처럼 들고 다닐 수 있는 제품을 다룹니다.
- 가구의 경첩·서랍 레일·의자 다리 교체와 흔들림 보강.
- 수도 설비의 수전 누수, 배수구 막힘, 샤워기 호스 교체.

평일 오전 9시부터 오후 6시까지 방문합니다. 야간·주말 방문은 제공하지 않습니다.

## 요금

방문 점검은 15,000원이며 수리를 진행하면 수리비에 포함됩니다. 기본 수리는 30,000원부터이며 부품비는 별도입니다.
